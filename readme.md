# 회원가입 웹 애플리케이션 (Sign-Up Form)

HTML5, CSS3, 바닐라 JavaScript(ES6+)로 구현한 회원가입 폼 및 가입 회원 목록 관리 웹 애플리케이션입니다.

## 주요 기능

- **아이디 유효성 및 중복 확인**
  - 영문 필수 포함, 숫자 선택 조합(영문·숫자 4~12자) 규칙 검사
  - `중복 확인` 버튼 클릭 시 기존 가입 회원 배열과의 중복 여부 검증
  - 중복 확인 완료 후 아이디 입력값을 수정하면 중복 확인 상태 자동 초기화
- **비밀번호 규칙 및 일치 여부 실시간 검증**
  - 8~16자 길이, 영문 대문자·소문자·숫자·특수문자(`!@#$%^&*`) 각각 1개 이상 포함 여부 실시간 확인
  - `비밀번호 확인` 입력 시 일치/불일치 상태 즉시 표시
- **이메일 형식 검증 및 제출 방어**
  - 기본 이메일 형식(`문자@문자.문자`) 검증
  - 미입력·규칙 위반·중복 확인 미완료 항목이 있으면 제출을 차단하고 해당 필드로 포커스 이동
- **회원 목록 출력 및 새로고침 유지 (`localStorage`)**
  - 유효한 가입 정보를 배열(`users`)에 추가하고 하단 `가입된 회원 목록`에 즉시 반영
  - `localStorage`(`signup_users_st`)에 데이터를 동기화하여 새로고침 후에도 회원 목록 유지

## 기술 스택

- **HTML5**: 시맨틱 태그 및 BEM 클래스 네이밍 기반 폼 구조 설계
- **CSS3**: `:root` 커스텀 프로퍼티, Flexbox 레이아웃, `rem` 및 `100dvh` 단위, `600px` 이하 반응형 대응
- **JavaScript (Vanilla JS)**: DOM 조작, 정규표현식 기반 유효성 검사, `localStorage` 데이터 영속성 관리

## 파일 구조

```text
├── index.html   # 회원가입 폼 및 가입된 회원 목록 마크업
├── style.css    # 레이아웃, 입력 오류/성공 상태 스타일, 반응형 스타일
├── script.js    # 유효성 검사, 중복 확인, localStorage 저장 및 목록 렌더링 로직
└── README.md    # 프로젝트 안내 문서
```

## 실행 방법

1. 저장소를 클론하거나 프로젝트 폴더를 다운로드합니다.
2. 브라우저에서 `index.html` 파일을 직접 열거나 VS Code의 **Live Server** 확장을 실행합니다.

## 보안 및 개선 고려 사항

- **XSS 방지**: 동적 회원 목록 렌더링 시 사용자 입력값을 `innerHTML` 문자열에 결합하지 않고 `document.createElement()`와 `textContent`를 사용해 텍스트로 안전하게 출력했습니다.
- **향후 개선 방향**: 실제 서비스 환경에서는 비밀번호를 클라이언트(`localStorage`)에 보관하지 않고 HTTPS로 서버에 전송한 뒤 안전한 단방향 해시 함수로 암호화하여 데이터베이스에 저장하는 구조로 분리해야 합니다.
